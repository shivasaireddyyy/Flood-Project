FloodShield sample CSV files (for testing only)
================================================
1_flood_training_sample.csv   -> Load Data tile: upload as the training dataset. SYNTHETIC data, not real observations.
2_shelters_sample.csv         -> Set Region tile: choose "My CSV" as safe-locations source and upload this.
                                 govt column: yes/no. DEMO names and approximate coordinates around Hyderabad.
3_station_directory_sample.csv-> SOS Dispatch tile: upload as the station directory. Placeholder phone/email only.
4_batch_areas_sample.csv      -> Batch Risk Map tile: upload after training on file 1.

Replace the DEMO rows with real shelters and stations of your area before using the results anywhere.
Use the same coordinates area (Hyderabad) when you set the region, or edit lat/lon in the files.
